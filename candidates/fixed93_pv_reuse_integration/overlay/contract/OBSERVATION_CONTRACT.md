## Required actual schedule and cache evidence

Preserve complete reconstructable accepted public command/request/completion/launch order; physical64-byte read payloads and addresses; write command/data/ACK/terminal/publication; Matrix group/step/seed/emit/retire and owner lease/epoch/ticket boundaries; real workspace begin/read/seed/write/ACK/version operations; resident FFN tile traffic; Attention packed FIFO borrow/score commit/retirement and selected fault checks. Original capped trace payloads must be retained in full by the independent stream capture, not only their prefixes or SHA256.

Object references are not a substitute for missing values. A reference is valid only when a source-bound corresponding raw record or algorithm array permits reconstruction. The declaration is a finite set of domains in capture/SCOPE.md and integration/EVIDENCE_INVENTORY.json, not a claim to observe every Python instruction, every RTL handshake or hidden hardware state.

Observers must be read-only: do not change operands/returns, suppress DUT exceptions, add arithmetic calls, retire extra events, mutate cache state, or repair missing observations from expected data. Capture failure remains sticky and prevents a complete seal; accepted debt must still be drained by the original owner. Fullblock observation uses a single composed single-thread trace dispatcher.
