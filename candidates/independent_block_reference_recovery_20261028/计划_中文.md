## 本轮实做

- 新增 `run_reference.py`，五个 profile 共用一份参考入口，调用各自已 pin 的完整官方 DecoderLayer forward。不是硬件模型、不是叶子算子测试，也不修改硬件。
- 完整参数集合为 12 / 14 / 11 / 18 / 15 个张量。按固定 checkpoint revision、官方 tensor name / shape / dtype / shard range 校验，严格加载单层全部参数。35B 包含完整专家张量，而非只下载被选专家。
- Qwen2 原参考执行本身为 BF16；原 FP32 输入/输出/系数传输格式保留。Dense 权重仍由硬件输入装配端使用原生 BF16，不能再扩成 FP32 权重。
- Qwen3.5 保留 checkpoint 中 A_log / gated norm 的原 F32 参数，其余 BF16。官方 forward、torch.topk、expert accumulation 顺序均不替换。小专家 ID 同分优先没有被接受或实施。
- 每块执行两次真正 M128 forward：无观测 baseline，再同一层、同一输入、独立全新冷 cache 的观测运行。要求输出和最终 cache 字节一致。此处两个调用是 baseline/observer 核对，不是两个 M1 假装 chunk。
- 观测只接收结果。输入目录只含 hidden、positions、RoPE、mask；专家 ID、router scores 和各阶段输出只在 reference_only，禁止用作硬件刺激。脚本没有硬件导入、launch 或路由注入接口。

## 新刺激身份

P0、P1/P2 为新的可重复外部 block 边界输入，不冒充原 embedding 或前级 block 输出。P3/P4 沿用既有独立实验输入生成算法，其 BF16 M128×2048 SHA256 为 c32e36dd356244838b17f8aebd8a0e647c5a09198365ad32c6f7996adef237bb。

这是完整单块回归的刺激选择，不证明 embedding→前三级 GDN→L3 的前缀语义。将来必须把同一份已验证 input_only 字节提供给 Chisel；模型完整通过后才能冻结并用于最终 RTL 回放。
