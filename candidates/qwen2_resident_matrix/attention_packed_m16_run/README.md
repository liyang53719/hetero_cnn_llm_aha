# Bounded original Public M16 execution wrapper

Preparation only until independent review and a separate root execution gate.
The default CLI validates frozen sources and prints a plan. No numerical job,
package installation, download, compiler, remote fetch, or CI is implicit.

One explicit attempt uses a fresh workspace and an exclusive persistent attempt
lock. Its one supervised child composes the exact linked entry, independently
clones the original clean be00 Git repository with --no-hardlinks, and overlays
only the exact generated source closure. It verifies committed scalar arithmetic
and reexecutes the retained CPython interpreter with -I -B at the same PID into
the installed Git root. The reexec clears preparation imports. It retains the
original context identity, source map and absolute monotonic deadlines.

The work alarm is 924 seconds from wrapper start. Five seconds are reserved for
TERM cleanup and one second for forced reap and final evidence, within a hard
930-second envelope. The original entry receives wall_budget=900. Slow source
composition, admission or postflight can exhaust the outer bound earlier; no
budget is extended. An external caller must use TERM at 924 seconds and KILL
at 930 seconds, not kill the wrapper at the work boundary without its cleanup
reserve. The parent continuously owns and monitors the child's process group;
Linux subreaping and PID start times cover descendants. A clean exec explicitly
clears inherited signal masking. During the tiny child exec timer gap the
parent timer remains armed. The child resumes against the same absolute work
deadline, never a new 924-second budget.

All runtime locations are explicit private CLI arguments: source root, original
be00 root, completed reference-preparation workspace, strict combined compile
receipt and source origin, fresh output workspace, retained interpreter, and
reviewed contract SHA256. The contract binds exact source bytes and CPython
version/size/hash, not private paths. Environment forwarding is allowlisted;
ISA overrides, loader overrides and Python path overrides fail closed. Production
uses normal Python only. No system environment or original workspace is changed.

Fresh linked admission preserves both original and fresh reference provenance,
strict combined-library identity, exact backend/source checks and the original
fixed numerical criteria. The original single Public run, causal reference gate,
physical loop, 21 events, 17 jobs and comparison functions remain in the linked
entry. Private returned and on-disk reports must JSON-roundtrip identically.
The child marker and parent postflight bind the same terminal bytes, snapshot,
source map, context and observed zero child exit. The caller must independently
observe a successful launcher exit before accepting its safe summary. A leftover
report or marker alone is not success.

Public progress is atomic bounded JSON containing only a fixed phase enum,
ordinal, writer PID, monotonic elapsed time and immutable context hash. A phase
completion never means numerical acceptance. Private model inputs, tensor
values, observations, full receipts and logs stay inside the private workspace.
Only bounded status/hash/count facts are emitted. Even a successful assigned
observed-node result does not establish full-29, RTL, hardware recipe or 90%
useful-wall-MAC acceptance. The original diagnostic-only softmax_fp32 stage is
not converted into an assigned numerical gate, and auxiliary independent-self-
cache failures are not silently promoted into the official acceptance policy.

Cold tests run with unittest normally and with -O. They exercise only synthetic
metadata and small stdlib control subprocesses; they do not load Torch, DUT
libraries, original reference producers, weights or numerical owner jobs.

## Terminal policy and trust boundary

The stdlib terminal validator checks the exact original 28 observed stage records,
27 assigned gates, diagnostic-only softmax_fp32, all ten causal capture fields,
15 whole-stage and six observed-node fixed-arithmetic results, 19 sealed outputs,

its bounded result explicitly leaves that to the observed child/launcher exits
and immutable context. Synthetic cold receipts are never numerical evidence.
