# 保序 32-lane RMS 局部模型证据

本目录仅保留有限数值/协议摘要和真实测试源码，不含 IR、SV、ELF、权重、参考数据、原始日志。测试实际使用 Chisel 发射局部 SV 后由 pinned Verilator 模拟；不是无 RTL 解释器，也不是全五块 M128 或最终冻结 RTL 验收。

原 155 源生产门保持不变并拒绝本候选；新 159 源闭包为 7 个替换、4 个新增，独立 MODEL_CANDIDATE 生成门仅授权收集候选结构。实际候选整体结构观察和五块数值仍待后续独立审核。

资源上限保留 RSS 1 GiB、模型 CPU 180 s / wall 210 s、旧 owner 5 GiB 与额外 1 GiB 余量。局部文件 cap 256 MiB、树 512 MiB；它们不扩大生产构建预算。所列 RSS 是采样，不是未来峰值保证。

早期真实失败保留在本地：Treadle CPU cap、PCH 文件上限/兼容性、一次监督 ESRCH、一次测试错误地把第二个已接收包后的新意图当作已 held 请求。最终 lease 测试显式先接收第二包，再跨边沿证明第三包 valid 且不 ready 后注入 fault；生产源码未为测试错误改语义。

租约测试只重编测试类，复用已严格完成的 11 源类型检查 classes；源身份/原回执由独立审核关联，不将单测试 INPUTS 冒充全部硬件编译闭包。
