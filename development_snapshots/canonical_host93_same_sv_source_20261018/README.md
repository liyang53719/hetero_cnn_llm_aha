No project bytecode is imported. A source-only wrapper call without the execution switch verifies the checker and does not read the large SV.

## Actual read-only gate

Actual execution is separately authorized. A caller must provide exact local paths and freeze a fixed-size/SHA same-raw-buffer wrapper launcher, the approved original SV identity and generation evidence, and a fresh report directory. This source publication does not bind a new machine, substitute another SV or authorize a native tool.

The wrapper keeps total90/pre10/check at most70 and no later than80/post90 seconds, one permitted CPU, CPU80 hard, AS1GiB and report/FSIZE2MiB. The immutable SHA-checked SV buffer is handed to check_bytes; original SV metadata/SHA and checker source are rechecked afterward. Unknown syntax or limits yield INCOMPLETE with original SV retained. Hard process/resource termination may prevent best-effort reporting. There is no regeneration or automatic retry.

The saved evidence is explicitly nonterminal: success also needs the original outer exit0, actual elapsed bound and independent actual review. A retained evidence file alone never grants success. SAFE_HISTORY.json records the two preserved incomplete predecessors and the latest bounded actual observation, separately from its review status.

The preserved final checker changes exactly those two guards: a nonidentifier/nonempty string marker retains line count, and the30 reserved concat names share the existing port rejection. The three small .sv files under checker are artificial negative fixtures, not the generated Host RTL. It did not read or copy the actual generated SV. Each fixture has a fixed size/SHA in test_cold.py, and each must raise its specified ValueError. Their generator source identity and origins are recorded in SOURCE_PROVENANCE.json; the generator is not a runtime dependency.
