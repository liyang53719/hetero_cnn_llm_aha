# 35B L0 实际 RMS → A/B 独立 N32 数值子门（2026-10-13）

## 结果与边界

原 checkpoint 的 M16 / M128 输入重新经过实际 H2048 RMS owner、写 ACK 和发布，
同一 MemoryRegion 接两个独立 A/B N32 投影，均取得 RMS/A/B 三个成功终态。
两档 A、B 各自逐 bit 等于官方原形状算子，也等于独立 C 配方输出。
M16 实际为 16 token；Matrix 执行补到 128 行。M128 是真实 128 token。
宿主运行分别 2.147462s / 11.159520s，不是硬件延迟。

本批只验 RMS→A→B，尚未把两输出重排成逐 token [A32,B32] 供 Prep 消费。
A_log/dt_bias 已获取但尚未在本批实际 Prep 中执行。Conv 没有重跑；32 头 chunk、
完整 L0/L3、生产 Chisel/Command128 和 RTL 仍开放。

## 固定资源、计数与性能证据层级

资源保持 Matrix4096、5 contexts、Vector16、Scalar1；N32 未减少固定分母。
每档 A+B 共 4 partial、4 次 Matrix acquire/release，实际 16777216 FMA。
M16 useful=2097152，算术 useful/executed=12.5%；M128 useful=16777216，算术比100%。
这些不是完整周期 MAC 利用率，也不隐藏其余 context 空闲。
VectorAdd：M16 共64调用/1024有效元素；M128共512调用/8192有效元素。
各阶段 DDR read/write/ACK、Scalar 操作和软件事务 ticks 全存机器报告。
硬件 cycle、busy duty、active-lane duty、stall/overlap 未测，不能声称80%或90%。
