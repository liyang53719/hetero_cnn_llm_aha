# FullBlock 进度观测与无 Git 冷测计划（2026-10-24）

## 1. 本批目标和边界

- 只增加可选、限频的进度观测，以及可在浅克隆或无 `.git` 源码归档中复现的冷测。原有数值运算、资源/身份检查频率、ACK、终态接受和 state/history 联合提交逻辑不变。
- `progress` 只接收脱离模型的不可变基础类型快照，不传递 owner、数组、资源句柄或控制对象；回调返回值不能驱动控制。它是受信任诊断 API，不是任意 Python 代码的安全沙箱。回调位于原 tick 资源检查之前，不进入最终接受/联合提交区间。
- 默认行为不变。显式 `window_budget_seconds` 使用“总预算剩余量与单窗口上限的较小值”，上限仍为 7200 秒；进度默认间隔 30 秒，合法范围为 1..7200 秒。进度事件不充当终态或数值通过证据。
